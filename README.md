# Multi-Website Designs (Figma UI/UX Showcase)

A comprehensive UI/UX case study and design system collection featuring four high-fidelity website interfaces crafted in Figma, focusing on intuitive data visualization, student-centered academic portals, and e-commerce digital experiences.


## Project Overview
As a UI/UX designer, balancing complex information architectures (such as course timetables, credit scores, and financial summaries) with clean, delightful visual aesthetics is a core challenge. This repository documents a curated collection of four web design explorations created both independently and collaboratively.

- **Role:** UI/UX Designer & Prototyper
- **Tools Used:** Figma
- **Year:** 2024 – 2026
- **Deliverables:** High-Fidelity Wireframes, Reusable Component Libraries, Interactive Prototypes

---

## Project Description 

### 1. EduPro — Academic Mobile Apps
* **Desc:** A Mobile Apps design that can predict pupils’ academic performance based on data such as attendance, assignment marks and exam results.
* **Focus:** Engineered a modular, card-based dashboard utilizing soft, eye-friendly pastel accents and clear typographic hierarchy for quick status checks on GPA, upcoming lectures, and assignment deadlines.

### 2. Floral & Co. — E-Commerce Plant Shop
* **Desc:** An e-commerce website design for selling trees, ornamental plants and gardening tools
* **Focus:** Minimalist, aesthetic e-commerce flow with emphasis on clean product photography cards, frictionless checkout steps, and plant care guides.

### 3. Mr. Coffee — Webstie CoffeeShop
* **Desc:** A website design where can view information about the café, browse the menu, place an order and make a payment
* **Focus:** Visual-first digital menu and ordering experience designed with appetizing warm color schemes, quick allergen filters, and smooth cart transitions.

### 4. SmartSpense — AI Daily Finance Tracker
* **Desc:** The AI Daily Finance Tracker project was developed using a combination of Convolutional Neural Networks (CNNs) and Recurrent Neural Networks (RNNs) to automatically analyse spending patterns, categorise expenditure and generate informative weekly financial reports.
* **Focus:** Unified style guide incorporating accessible contrast ratios, auto-layout component sets, responsive breakpoints, and consistent icon sets.
